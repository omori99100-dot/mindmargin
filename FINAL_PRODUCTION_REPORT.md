## Issues & Warnings

### Non-Blocking Warnings
1. **LLM JSON Parsing:** Scene planning and quality scoring occasionally return invalid JSON, triggering default fallbacks. The `qwen2.5:0.5b` model struggled with structured JSON output.
2. **Research Enhancement:** ResearchAgent uses `generate_json_sync` but `ResearchAgent` doesn't always have an LLM reference. Fixed by using `provider_manager` to create default LLM.
3. **Script Agent Slow:** Each LLM call takes 1-2 minutes with `qwen2.5:0.5b`. In production with faster models, this is not an issue.
4. **Template Mode:** ScriptAgent template sections are short (~32 words); quality gate triggers regeneration. Works correctly but slow.

### No Blocking Issues Found
