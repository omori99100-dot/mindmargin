# MindMargin — Deployment Checklist

Use this checklist before launching MindMargin in production.

---

## Pre-Deployment

- [ ] Repository cloned to target machine
- [ ] Python 3.11+ installed
- [ ] FFmpeg installed and on PATH
- [ ] Piper TTS installed (optional — falls back to silent audio)
- [ ] Ollama installed and running with `qwen2.5:0.5b` model
- [ ] `pip install -r requirements.txt` completed
- [ ] `.env` file configured (see `.env.example`)
- [ ] `config/settings.yaml` reviewed and customized

---

## YouTube OAuth

- [ ] Google Cloud project created
- [ ] YouTube Data API v3 enabled
- [ ] OAuth consent screen configured
- [ ] OAuth client ID created (Desktop app type)
- [ ] `client_secrets.json` downloaded and placed in project root
- [ ] Token generated by running `_get_authenticated_service()` locally
- [ ] `youtube_token.pickle` saved in project root
- [ ] YouTube channel verified: `python -m mindmargin.main --check-auth`

---

## GitHub Actions

- [ ] `YOUTUBE_TOKEN_B64` secret configured
- [ ] `ENV_FILE` secret configured
- [ ] `CLIENT_SECRETS` secret configured
- [ ] `TELEGRAM_BOT_TOKEN` secret configured (optional)
- [ ] `TELEGRAM_CHAT_ID` secret configured (optional)
- [ ] Workflow permissions set to "Read and write"
- [ ] Actions enabled on repository
- [ ] Daily Job workflow enabled
- [ ] Manual test run completed successfully

---

## Local Verification

- [ ] `python -m mindmargin.main --check-auth` → authenticated
- [ ] `python -m mindmargin.main --channel-status` → shows channel info
- [ ] `python -m mindmargin.main --topic "test" --quick` → pipeline completes
- [ ] `python -m mindmargin.main --execute-brain` → decision executor runs
- [ ] All unit tests pass: `python -m pytest tests/ -q`

---

## Docker Deployment (Optional)

- [ ] Docker installed
- [ ] Docker Compose installed
- [ ] `./deploy/deploy.sh dev` → starts successfully
- [ ] Health check: `curl http://localhost:8000/health` → `{"status": "ok"}`
- [ ] API docs accessible: `http://localhost:8000/docs`

---

## Production Deployment

- [ ] `.env` set to `ENVIRONMENT=production`
- [ ] `LOG_LEVEL` set to `INFO` (not DEBUG)
- [ ] `DEBUG=false`
- [ ] SSL certificates configured (if using HTTPS)
- [ ] Resource limits set in docker-compose.prod.yml
- [ ] Backup strategy for `data/mindmargin.db` configured
- [ ] Monitoring/alerting configured

---

## Post-Deployment

- [ ] First daily job completed successfully
- [ ] Video uploaded to YouTube
- [ ] Video verified on YouTube channel
- [ ] Telegram notifications working (if configured)
- [ ] Logs reviewed for errors
- [ ] Database backup scheduled

---

## Ongoing Operations

- [ ] Monitor YouTube channel health score
- [ ] Review decision executor logs daily
- [ ] Check circuit breaker status weekly
- [ ] Rotate YouTube token before expiry (tokens expire after 7 days of non-use)
- [ ] Update dependencies monthly

---

## Emergency Procedures

### Circuit Breaker Tripped
1. Check execution logs for root cause
2. Fix the underlying issue
3. Reset: `python -m mindmargin.main --executive-status` then reset in code

### YouTube Token Expired
1. Regenerate token locally: run `_get_authenticated_service()`
2. Update `YOUTUBE_TOKEN_B64` GitHub Secret
3. Re-run the daily job

### Database Corrupted
1. Stop the worker
2. Restore from backup: `cp backup/mindmargin.db data/mindmargin.db`
3. Restart the worker
